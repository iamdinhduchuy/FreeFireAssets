## 🌟 Overview

**FreeFireAssets** provides transparent, trimmed, and optimized `.png` images from **Garena Free Fire**. Every asset is structured neatly into standard categories, making it seamless to integrate into:

- 🤖 **Chatbots**: Discord, Telegram, Messenger bots (profile stats, weapon stats, loadout pickers).
- 🏆 **Esports & Streams**: Tournament overlays, broadcast scoreboards, live kill feeds.
- 🌐 **Web Applications & Tools**: Strategy planners, character skill builders, tier-list makers.
- 📱 **Mobile & Desktop Apps**: Free Fire companion apps, weapon damage calculators.
- 🎨 **Graphic Design**: Thumbnails, banners, infographics, social media posts.

Clone the entire repository locally:

```bash

```

Or download as a ZIP archive directly from the GitHub releases / repository page.

### Option 2: Free CDN (jsDelivr) *(Recommended for Web & Bots)*

You can serve any asset worldwide with fast caching using the **jsDelivr CDN** without hosting files on your own server:

**CDN URL Structure:**
```
https://cdn.jsdelivr.net/gh/iamdinhduchuy/FreeFireAssets@main/<FOLDER>/<FILENAME>.png
```

> **Note**: URLs with spaces should be encoded with `%20` (e.g., `Alok%20Awaken.png`).

## 📐 Asset Quality & Guidelines

All assets in this repository adhere to the following standards:

1. **Format**: Portable Network Graphics (`.png`).
2. **Color Mode**: 32-bit ARGB with clean Alpha channel transparency.
3. **Cropping**: Tight bounding box crop without unnecessary surrounding whitespace.
4. **Naming Convention**:
   - Weapons: Official in-game names in uppercase or PascalCase (e.g. `M1014-III.png`, `AK47.png`).
   - Characters: Official character name (e.g. `Tatsuya.png`, `Kelly Awaken.png`).
   - Loadouts: Full title capitalization (e.g. `Tactical Market.png`).
   - HeadPics: 9-digit numeric ID format (e.g. `902000006.png`).

## 🤝 How to Contribute

Contributions are warmly welcomed! If you have missing assets from recent Free Fire updates (OB patches) or higher quality renders:

1. **Fork** this repository.
2. **Create a branch** for your update:
   ```bash
   git checkout -b feat/add-new-character
   ```
3. **Add assets** to the corresponding folder:
   - Ensure the image has a **transparent background** (`.png`).
   - Remove background artifacts, stray pixels, and maintain correct aspect ratio.
   - Follow existing naming conventions.
4. **Commit** your changes:
   ```bash
   git commit -m "feat(character): add new character Orion Awaken"
   ```
5. **Push** to your fork and submit a **Pull Request (PR)**!
